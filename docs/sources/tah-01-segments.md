# Kitāb al-Ṭahāra — segments du matn dans Mawāhib al-Jalīl (squelette tah-01)

Source : *Mawāhib al-Jalīl*, éd. Dār al-Fikr 1992, t. 1, p. 43–377 (shamela.ws/book/569, pages 42–376), lue intégralement le 2026-11-02.
Extraction : chaque segment « ص (…) ش » du texte (y compris 4 segments sans « ش » : p. 58, 93, 98, 316). Texte reproduit tel qu'imprimé, sans correction.
Contrôle : chaque section a été recopiée puis comparée à l'empreinte SHA-256 calculée sur Shamela (segments joints par un saut de ligne) — 11 empreintes identiques.
Découpage : un seul bāb dans le matn ; sections = ouverture du bāb (sans titre) + les « فَصْلٌ » du matn, confirmés par les titres de l'édition. Le faṣl des convenances (p. 267) et celui du mash sur les khouff (p. 318) sont titrés par l'édition ; le second porte aussi « فَصْلُ » dans le matn.

Anomalies d'impression relevées (à signaler dans les fiches concernées) : tah-01-01-03 « أَوَذَابَ » (pour « أَوْ ذَابَ ») ; tah-01-04-56 « كَ شَكِّهِ » (espace) ; tah-01-05-01 « وَمِنْهُ بِرَخْوٍ » (lecture à contrôler) ; tah-01-08-22 se termine par « أَقْوَالٌ: ».

Lectures contrôlées (campagne de correction du 2026-11-03, seconds témoins ; le tableau ci-dessous reste tel qu'imprimé, pour conserver les empreintes) :
- tah-01-04-56 : lire « كَشَكِّهِ » d'un seul mot — Mukhtaṣar seul (shamela.ws/book/11355, p. 13) et Shifāʾ al-Ghalīl d'Ibn Ghāzī (shamela.ws/book/14605, p. 30).
- tah-01-05-01 : lire « وَمُنِعَ بِرَخْوٍ نَجِسٍ » (« il est interdit [de s'asseoir] sur un sol meuble impur ») — Mukhtaṣar seul (11355, p. 14 : « ومنع برخو نجس ») et Shifāʾ al-Ghalīl (14605, p. 31 et 33). « وَمِنْهُ » est une faute d'impression. Titre arabe corrigé dans `data/plan.js` v1.8.
- tah-01-08-22 : le segment se termine par « أَقْوَالٌ » sans deux-points — Mukhtaṣar seul (11355, p. 21). Ce témoin porte aussi « تَيَمُّمِهِ أَوْ مَسْحِهِ » là où Mawāhib imprime « تَيَمُّمِهِ وَمَسْحِهِ » : à examiner quand la masʾala sera traitée.
